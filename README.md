# Kunde Code Exercises

Hi guys! This is the Kunde Code exercise repository.

This is where you'll find the coding and technology exercises we'll work through during the program.

## Building Toward Our Final App

Every exercise in this repository is a **building block toward our final app**.

We're not learning random skills just to learn them. Each week, you'll learn something new and use it to build another part of the project.

By the end of the program, we'll have built a real application designed to help Sudanese newcomers find community resources in Ottawa.

## Weekly Exercises

Each week has its own folder.

New weeks will be added as we get to them, so you may not see every week right away.

```text
kunde-code-exercises/
├── week3/
├── week4/
└── week5/
```

## Getting Started

Before you start, make sure you have:

* VS Code
* Python
* Git
* A GitHub account

You don't need an AWS account for the exercises.

### Clone the repository

In VS Code:

1. Press `Cmd + Shift + P` on Mac.
2. Search for **Git: Clone**.
3. Paste the repository link provided by Whitney.
4. Choose where you want to save the project.
5. Open the repository in VS Code.

## Your Group's Folder

Some exercises are organized by group.

For example:

```text
week3/
└── Part_4_Prompt/
    ├── Food_Security/
    ├── Health_Care/
    ├── Housing/
    ├── Legal_Immigration/
    └── Mental_Health/
```

**Only work inside your assigned group's folder.**

Please don't:

* Edit another group's files
* Delete another group's files
* Move files between groups
* Change shared code unless Whitney asks you to

## Uploading Your Work

When you're finished:

1. Save your files.
2. Open **Source Control** in VS Code.
3. Stage your changes by clicking `+`.
4. Write a short commit message.

For example:

```text
Add housing prompt
```

5. Click **Commit**.
6. Click **Sync Changes** or **Push**.

Your work will then be uploaded to GitHub.

## Work Together

These are group exercises, so talk through your ideas with your teammates.

You won't always get things right on the first try. That's normal. Try things, see what happens, ask questions, and improve your work.

The goal is to learn while actually building something together.

## Keep Your Information Private

Never upload:

* Passwords
* API keys
* AWS credentials
* `.env` files
* Other private or sensitive information

If you're not sure whether something is safe to upload, ask Whitney.
